CRONOLOGÍA SIMULADA
  1. Proyecto creado

    Solo un ejemplo visual. En producción quedarán guardados identidad, autor y contrato.

  2. Fixture de datos asociada

    Los hashes y la procedencia serán comprobados por el servidor; no se aceptarán campos enviados por un móvil como autoridad.

  3. Estado provisional

    Una transición científica real requiere autorización y evidencias verificables. Este ejemplo no ha generado un evento M2 auténtico.

No se muestra ningún SHA-256 simulado como si fuera real. El servicio todavía no está emparejado con el motor C++20.
