# QROS Mobile Companion — isolated scope, preregistered 2026-09-25

This is a new product descendant and does not rewrite the frozen Windows-first QROS Research Studio MVP contract, which explicitly excludes native mobile.

## First user loop (TEST_ONLY)

- Create a read-only mock mobile client with Project List, Project Detail, History and Evidence Status.
- The Windows/local workstation remains the only compute and market-data holder.
- Display scientific state and execution annotation separately, including immutable event digest and independent anchor verification status.
- Explain denied transition attempts and blockers without silently presenting pending steps as scientific PASS.
- In a later gated increment, accept bounded typed job requests through a server-side API that authenticates users and never takes TransitionActor=QROS_CORE or TransitionContext booleans from a handset.

## Security gates before real pairing

Device authentication and revocation; encrypted transport; server authorization; tenant isolation; no broker credentials or raw tick carriers on the phone; no holdout reads or arbitrary filesystem paths from API; audit all requested transitions. Mobile has ZERO scientific authority.

## Out of mobile M0

Remote live trading, automated MT5 orders, strategy marketplace, subscriptions, cloud compute, proprietary alpha distribution, persistent push notifications and paid external services.

## Exit criteria

Mock screens, accessibility and failure states, non-economic synthetic projects only, no credential exposure, immutable read-only event visualization and a separately reviewed API threat model. No real-data launch until desktop M2 is production-qualified.
