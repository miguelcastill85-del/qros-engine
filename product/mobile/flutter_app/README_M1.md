# QROS Mobile M1 Android — authenticated read-only synthetic sample

M0 UI and 6 earlier tests remain. M1 adds `lib/core/verified_demo.dart`, `lib/ui/verified_demo_screen.dart` and integration tests using the same public synthetic signed fixture generated by the Python backend.

- Navigation: Seguridad → Consultar demo firmada. User enters HTTPS origin and a disposable token **at runtime only**. Nothing is stored or bundled.
- The app verifies independent Ed25519 witness and receipt signatures, exact frozen external anchor body SHA-256 and demo-only `SIMULATED_SAMPLE` flags. It does not grant PASS, send a transition or connect to a real broker.
- A local dependency-injected gateway tests the interface offline; Python loopback backend tests exercise the real HTTP server. Connecting Android to a **real** HTTPS ingress and installation tests on a physical handset remain separate acceptance gates.

CI pins Flutter 3.35.4 and Java 17 and builds a **debug** TEST_ONLY APK. The previous M0 APK remains an archived checked artifact and must not be confused with this M1 build. No Windows user interface or desktop installer is in scope.
