# QROS Mobile — Mechanical anti-stall delivery contract v1

A prompt is not an enforcement mechanism. Progress **MUST** be proven by changed source bytes and a job executed against the same exact Git commit before any engineering PASS or HEAD promotion.

**No-op fail-closed:** A proposed phase review containing only another HEAD recovery, a prose plan, new memory instructions or an unrun script cannot satisfy the source delta gate. If there is no actual change, report it as status only, never as a completed phase.

**On every phase:** (1) read exact current product HEAD ONCE and validate its source pins; (2) select one authorized next action; (3) implement a minimal bounded runnable delta; (4) test locally where tools exist; (5) push on isolated non-main branch; (6) run same-commit CI source-hash, regression, independent-oracle and negative/adversarial gates; (7) preserve raw CI receipt even if the ephemeral artifact expires; (8) independently check source commit, hashes, CI conclusion and failed historical runs; (9) promote a new exact HEAD with the next legitimate delta; (10) continue only if time/tools allow.

**Recovery is budgeted:** if a matching complete HEAD and pins were already authenticated in the turn, do not fetch them again without positive drift evidence. Do not repeatedly list the repository while a concrete next code step is available. A stalled worker must emit a bounded checkpoint with the exact failing test, affected file, probable cause, attempted alternative and independent safe route; it may never issue fake scientific PASS or repeat already verified shards.

**Enforcement surface:** GitHub Actions CI source gate rejects no-op diffs, missing tests, unregistered files, tampered source, mutated baseline pointer and unauthorized status transitions. The companion adversarial tests deliberately try to bypass the gate. Branch protection or org-wide required status checks are NOT enabled by this document and require separately demonstrated GitHub configuration/permissions. A malicious repository administrator can override unprotected CI; a dynamic independently governed external witness remains a release prerequisite.

**Hard scientific firewall:** mobile clients and AI never sign scientific transitions or open holdout. Real broker data, PF, capital deployment and live MT5 are outside these G2/G3 engineering gates. Synthetic sample counts are not alpha or backtest coverage.

**Execution reality:** This guard blocks false GitHub phase promotion; it cannot force the ChatGPT runtime to keep working after its turn ends. Persist source and a truthful next action so another turn resumes the minimal remaining delta.
