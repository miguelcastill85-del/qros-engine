# QROS Fast Frontier v2 (Android chat)

Uses SHA-pinned initial 446/710 frontier and the live scientific pointer to avoid downloading or rehashing 446 completed receipts every chat. Compact source: anti_stall/chat/qros_fast_resume_v2.py. It verifies exactly the live Git target, anchor, bitmap, counter, root and original frozen data/plan/runner SHA pins. Fetch latest delta only, if present. During actual computation fetch original broker carrier and V28 frozen tapes, run only up to 6 unexecuted original tasks, verify independently, upload original receipt bytes in ONE atomic Git tree/commit with non-forced ref update and independent readback. Full audit every 20 delta publications. No PC needed for active-turn precheck. No execution after response ends. Gate A/holdout/GA2 remain closed. The full 26KB incremental writer passed local tests but is not deployed in Git yet; existing Git v1 delta writer remains the executable fallback when publishing new results.
