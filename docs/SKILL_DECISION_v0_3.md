# Decisión sobre skill — v0.3

No crear todavía una skill que sea autoridad del software.

La autoridad actual es:

`source + contratos + tests + golden ledgers + hashes + receipts`.

Una futura `qros-engine-builder` será útil cuando los contratos de ingestión productiva, holdout y promoción estén congelados. Su función será orquestar build, sanitizers, analyzers, paridad, benchmarks y promotion gates. No podrá redefinir causalidad, Bid/Ask, sessions, holdout ni reglas científicas.
